# ربات جستجوی آهنگ و ویدیو — نسخه MVP

نسخه راه‌اندازی (launch): ساده، واقعی و قابل اجرا، با دو قابلیت اصلی — شناسایی/جستجوی آهنگ و تبدیل متن فارسی به ویس.

## MVP شامل چیست
- منوی فارسی و دستورهای `/start` ،`/help` ،`/cancel`
- جستجو از یک منبع رایگان و بدون کلید: iTunes Search API (آهنگ و موزیک‌ویدیو)
- پردازش لینک: فهرست مجاز دامنه، اعتبارسنجی، مسدودسازی IP خصوصی و SSRF،
  فقط لینک رسمی منبع؛ بدون دور زدن DRM یا پرداخت
- پنل مدیریت داخل تلگرام، فقط برای مالک (`OWNER_ID`)، با روشن/خاموش کردن
  چند قابلیت اصلی که در پایگاه داده ذخیره می‌شود
- توکن فقط از متغیر محیطی (`.env`)، هرگز در کد نیست
- پایگاه داده SQLite با فایل مهاجرت نسخه‌بندی‌شده در `migrations/`

## لایه هوش برتر و خروجی حرفه‌ای بعد از جستجو
- **مغز ربات: OpenAI (ChatGPT)** با یک کلید `OPENAI_API_KEY` برای هر سه کار:
  فهم قصد متن آزاد (نام آهنگ / نام خواننده / خط ترانه) و تمیز کردن آن
  به یک عبارت جستجو، تبدیل ویس به متن با Whisper، و تبدیل متن به ویس
  با TTS (زن: nova، مرد: onyx؛ فارسی و انگلیسی). بدون کلید، ربات صادقانه
  می‌گوید هوش برتر وصل نیست و جواب جعلی نمی‌سازد؛ جستجوی پایه‌ای
  قانون‌مند بدون کلید هم کار می‌کند.
  توجه: «وصل شدن به خود Muse» به‌عنوان API برای کد ربات ممکن نیست؛
  معادل عملی آن همین OpenAI است.
- **شناسایی آهنگ: Shazam اول (بدون توکن)** — امضای صوتی ویدیو/فایل
  ارسالی یا فایل رسانه لینک، با AudD به‌عنوان جایگزین در صورت تنظیم
  توکن. نتیجه کاتالوگ هرگز «شناسایی‌شده» خوانده نمی‌شود و آهنگ نزدیک
  نامربوط هرگز به‌جای آهنگ شناسایی‌شده نشان داده نمی‌شود.
- **خروجی بعد از جستجو، حرفه‌ای و مینیمال:** فقط ویدیوی همان لینک،
  یک خط تمیز «عنوان – خواننده»، و فایل صوتی پیش‌نمایش قانونی با لینک
  رسمی دانلود/خرید در توضیح آن. بدون دکمه‌های Google/YouTube Music/
  Spotify، بدون دکمه آمار، بدون بخش‌های خالی «پیدا نشد» و بدون جستجوی
  ویدیو برای لینک. فایل کامل دارای حق نشر از منابع غیرمجاز دانلود و
  بازارسال نمی‌شود؛ نسخه کامل فقط از فروشگاه رسمی است.
- **جایگزین گفتار:** Azure Speech (زن fa-IR-DilaraNeural، مرد
  fa-IR-FaridNeural؛ تشخیص گفتار fa-IR) فقط وقتی OpenAI تنظیم نشده یا
  خطا بدهد.

## MVP شامل نیست (به‌عمد، تا تأیید بعدی)
وب‌پنل، تبلیغات، چند موتور جستجو، یوتیوب با کلید API، اشتراک ویژه،
مدیریت پیشرفته کاربران، آمار و گزارش‌ها، PostgreSQL ،Redis ،Docker.

## اجرای محلی (کوتاه)
```bash
cd telegram-media-platform
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env   # سپس BOT_TOKEN و OWNER_ID را وارد کنید
.venv/bin/python -m app.main
```

آزمایش‌ها:
```bash
.venv/bin/python -m pytest tests/ -q
```

جزئیات: `docs/run.md` و `docs/status.md` را ببینید.
