# راهنمای نصب و اجرای محلی (MVP، فارسی)

## پیش‌نیازها
- Python 3.12
- یک ربات ساخته‌شده در BotFather (فقط برای گرفتن توکن؛ توکن را در چت عمومی نفرستید)

## گام‌ها
1. `python3 -m venv .venv`
2. `.venv/bin/pip install -r requirements.txt`
3. `cp .env.example .env` و در `.env` بنویسید:
   - `BOT_TOKEN=توکن_بات_شما`
   - `OWNER_ID=شناسه_عددی_تلگرام_شما`
4. اجرا: `.venv/bin/python -m app.main`
5. در تلگرام `/start` را بزنید. پنل مالک: `/admin` (فقط با همان OWNER_ID باز می‌شود).

## آزمایش
```bash
.venv/bin/python -m pytest tests/ -q
```
بدون توکن، برنامه با پیام واضح متوقف می‌شود و خطای traceback نمی‌دهد.

## پشتیبان‌گیری
فایل پایگاه داده در `data/bot.db` است (مسیر با `DB_PATH` قابل تغییر است).
برای پشتیبان، همان فایل را کپی کنید؛ ربات را هنگام کپی متوقف کنید.

## محدودیت‌های MVP
- جستجو فقط iTunes است؛ اگر iTunes در دسترس نباشد، پیام خطای مناسب نمایش داده می‌شود.
- لینک یوتیوب/اینستاگرام/آپارات فقط لینک رسمی برمی‌گرداند؛ دانلود محتوای محافظت‌شده انجام نمی‌شود.
- وب‌پنل، تبلیغات و اشتراک در MVP نیستند.
